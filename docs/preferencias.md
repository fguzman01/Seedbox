# Preferencias de Felipe sobre las fichas de oportunidad

Lo mantiene el evaluador (`seedbox-evaluator`, H20, ADR-0013) a partir de los issues `tipo:oportunidad`:
✅ = quiere explorarla (cerrado `completed` o `estado:hecha`); ❌ = descartada (cerrado `not_planned` o
`estado:descartada`). Se actualiza sólo cuando hay decisiones nuevas, por PR (pide ✅ de Felipe). Cada
ficha cita la versión usada. Si no dejó motivo se anota «sin motivo»; no se inventa.
